## PHASE 1 — Media analysis + Design decisions

### Problem: batch-reading 74 photos

Reading 6+ images in parallel hit a "many-image" hard limit. Solution: generated 900px thumbnails into `_thumbs/` via PIL, then read one at a time sequentially.

```python
# thumbnail generation script (generate_thumbs.py)
from PIL import Image
from pathlib import Path

PHOTOS = Path("site/photos")
THUMBS = PHOTOS / "_thumbs"
THUMBS.mkdir(exist_ok=True)

for p in PHOTOS.glob("*.jpg"):
    if p.stem.startswith("_"):
        continue
    img = Image.open(p)
    img.thumbnail((900, 900))
    # RGBA→RGB before saving as JPEG (avoids OSError: cannot write mode RGBA as JPEG)
    if img.mode != "RGB":
        img = img.convert("RGB")
    img.save(THUMBS / p.name, "JPEG", quality=85)
```

**Key bug avoided**: RGBA PNGs (logo) fail to save as JPEG — always convert mode before saving thumbnails.

## PHASE 5 — Audit anti-hallucination (audit_content.py)

### Critical regex bug

`audit_content.py` had false positives: 210 warnings on clean content.

**Root cause:** Regex `\b([A-ZÀ-Ÿ][a-zà-ÿ]{2,15})\b` — the range `À-Ÿ` (U+00C0-U+0178) includes lowercase accented chars in U+00DF-U+00FF (ß, à, á, â, ã, ä, å, æ, ç, è, é, ê, ë, ì, í, î, ï, ð, ñ, ò, ó, ô, õ, ö, ÷, ø, ù, ú, û, ü, ý, þ, ÿ). So `\b([À-Ÿ]...)` matched words starting with lowercase accented letters.

**Fix:**
```python
# Before (wrong — includes lowercase in À-Ÿ range):
pattern = r'\b([A-ZÀ-Ÿ][a-zà-ÿ]{2,15})\b'

# After (correct — uppercase only):
pattern = r'\b([A-ZÀ-ÖØ-Þ][a-zà-öø-ÿ]{2,15})\b'
# U+00C0-U+00D6 = À-Ö (uppercase)
# U+00D7 = × (multiplication sign, skip)
# U+00D8-U+00DE = Ø-Þ (uppercase)
```

Additional fixes to reduce legitimate false positives:
- `DATE_WHITELIST = {"1978","2016","2018","2024","2025","2026","2027"}` — actual years in legal pages
- `DURATION_WHITELIST_SUBSTRINGS` — "3 ans", "10 ans" etc. for RGPD retention periods
- Expanded `NAME_WHITELIST` — Pays Basque communes (Anglet, Biarritz, Boucau, etc.), plumbing brands (Grohe, Grundfos, Viessmann), common French words falsely flagged

Result: 210 warnings → 13 OK, 0 ambiguous, 0 hallucinations → "RAS — prêt pour PHASE 6".

## PHASE logo fix — Transparent PNG

**Problem:** `logo.jpg` had white/cream background that appeared black in the HTML header (browser rendering artefact when JPG has no alpha channel and is placed on a light `#fbfaf6` background — actually the issue was the footer `bg-white rounded-md p-1.5` wrapper that was visually inconsistent, but the root was the missing transparency).

More precisely: the logo file was a JPG with white background. On the light `#fbfaf6` header it was fine visually. The **actual reported issue** was that in the header it appeared black — this was because earlier the header had a temporary dark state or the logo.jpg itself had near-black pixels around the edges.

**Fix — `_fix_logo.py`:**
```python
from PIL import Image
from pathlib import Path

img = Image.open("site/photos/logo.jpg").convert("RGBA")
data = img.getdata()
new_data = []
for r, g, b, a in data:
    if r <= 35 and g <= 35 and b <= 35:
        # Near-black → fully transparent
        new_data.append((r, g, b, 0))
    elif r <= 80 and g <= 80 and b <= 80:
        # Dark edge → partial alpha for anti-aliasing
        alpha = int(((r + g + b) / 3) * 3)
        new_data.append((r, g, b, alpha))
    else:
        new_data.append((r, g, b, a))
img.putdata(new_data)
img.save("site/photos/logo.png", "PNG")
img.save("site/photos/logo.webp", "WEBP", lossless=True)
```

All 7 HTML files updated:
- `src="photos/logo.jpg"` → `src="photos/logo.png"` in `<img>` tags
- `srcset="photos/logo.jpg"` → `srcset="photos/logo.webp"` in `<source>` tags
- Removed `bg-white rounded-md p-1.5` wrapper from footer logos (4 files)

## Key patterns

1. **"Script collecte, LLM analyse"** — the scraper generates raw data; Claude reads it and decides. Never pre-classify in the script. Claude needs to read reviews_all.json and count mentions manually.

2. **Anti-hallucination seuils** — 0 mentions = forbidden. 1 mention = exception (quote only, don't generalise). 2-3 mentions = probable (OK to state). ≥4 mentions = verified (affirm freely). Apply especially to: names, guarantees, prices, certifications, timelines.

3. **VoC-driven headlines** — using the actual name (Denis, 10×) + actual service (fuite, 31×) + actual city (Bayonne, profil.json) produces memorable headlines vs generic "Votre artisan de confiance". The formula: `[Name] + [verb that solves pain] + [specific service] + [city]`.

4. **reviews_inline.js over fetch()** — `fetch('reviews.json')` is blocked in `file://` (CORS) AND is async (blank above-fold during screenshot QC). Inline JS in `window.SITE_REVIEWS` is synchronous and works everywhere.

5. **Alias URL for finalize** — Vercel returns two URLs per deploy: deployment-specific (changes each time) and stable alias (constant). Always use the alias in finalize_site.py.

6. **Logo files: always PNG/WebP with alpha** — JPG cannot hold transparency. If source is JPG with white/black background, use PIL to convert dark pixels to transparent before using in HTML.
